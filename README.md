## 🧭 Overview

This workspace was developed to showcase the **CSC-202: Programming Microcontrollers in C and Assembly** final project developed by Tyler Huynh and Adnan Heganovic.

It includes starter code, configuration examples, and documentation to support student projects using the MSPM0G3507 LaunchPad, BOOSTXL-EDUMKII, and RFID RC522 module with Code Composer Studio – Theia Edition.

In addition to this, this workspace also includes a recreation of the popular Atari game Breakout designed to be used with the BOOSTXL-EDUMKII and MSPM0G3507.

An SDK of the BOOSTXL-EDUMKII created by Ryanne Geiger utilized as well.
